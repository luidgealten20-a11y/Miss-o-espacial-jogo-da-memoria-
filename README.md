# Missão Espacial — Jogo da Memória

## Como executar
1. Extraia os arquivos para uma pasta.
2. Abra o arquivo `index.html` em um navegador atualizado.
3. Clique em duas cartas por vez e encontre os oito pares.
4. Use **Recomeçar** para iniciar uma nova partida.

## Arquivos
- `index.html`: estrutura da página.
- `style.css`: aparência e adaptação para telas menores.
- `script.js`: embaralhamento, regras, movimentos, pares e cronômetro.
